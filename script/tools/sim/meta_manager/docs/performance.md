# Profiling the simulator

Use the bundled examples or the seeded random workload; no external trace or
saved benchmark artifact is required. Follow [setup](../README.md#setup-and-examples)
and activate the virtual environment first.

Warm the incremental native build, then profile an ordered random workload:

```bash
python examples/random_example.py
python -m cProfile -o build/random.pstats sim_random.py \
  --accesses 10000 --key-count 1000 --capacity 64MiB --seed 42
python -c 'import pstats; pstats.Stats("build/random.pstats").sort_stats("tottime").print_stats(20)'
```

`build/random.pstats` is generated by that command. Inspect cumulative time
with `sort_stats("cumtime")`; cumulative times include callees and must not be
added together indiscriminately. The profile covers the entrypoint, including
imports, incremental build checks, setup, replay, and reporting. The report's
replay wall time covers a narrower boundary described in [design](design.md).

Native API totals come from C++ steady-clock timers around `Get`, `Alloc`,
read/write completion, and watermark checks. They include synchronous native
work and lock waits, exclude binding conversion and background-worker CPU,
and do not provide a complete C++ CPU profile. In concurrent mode native call
durations can overlap, and the main-thread Python profile omits worker work.
Do not identify wall time outside those timers as pure Python CPU time.

Current observation construction shares immutable results with lease tokens,
reads descriptor lists once per conversion, uses slots for frequent records,
and reuses metric groups through `defaultdict`. Derived report summaries run
after replay. These choices reduce Python bookkeeping without changing the
manager flow or dropping metrics.

For a timing comparison, use separate unprofiled runs with identical input,
configuration, interpreter, and native extension digest. Check allocation and
completion counts as well as time. Native eviction is asynchronous, so use a
pool large enough to avoid eviction when exact cache outcomes are required.
The bundled trace example supplies a small deterministic count check; it is
not a throughput benchmark. No host-independent speedup is claimed.
